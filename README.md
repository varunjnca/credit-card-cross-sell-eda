# Credit Card Cross-Sell EDA

Exploratory data analysis of customer and bank-relationship data to identify patterns relevant to credit-card cross-selling.

## Contents

- `credit-card-cross-sell-eda.ipynb` — Jupyter notebook with the analysis.

## Getting started

Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab and run the cells in order. Install any Python packages requested by the notebook if they are not already available.

## Data

Refer to the notebook for dataset details and any source or access requirements.
